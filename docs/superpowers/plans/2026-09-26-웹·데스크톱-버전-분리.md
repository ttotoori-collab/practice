# 웹/데스크톱 버전 분리 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 기존 tkinter 데스크톱 앱을 `desktop_version/` 으로 옮기고, 같은 가중치로 동작하는 순수 자바스크립트 웹 앱을 `web_version/` 에 새로 만든다.

**Architecture:** 학습과 가중치는 데스크톱이 단독으로 책임진다. 빌드 도구로 `mnist_cnn.pt` 를 Float32 바이너리로 한 번 변환해 두고, 웹은 그것을 `fetch` 해서 직접 구현한 CNN 순전파에 넣는다. `app.py` 의 `전처리()` 6단계를 자바스크립트로 그대로 옮기되, 축소 필터는 브라우저마다 결과가 다른 canvas `drawImage` 대신 PIL 의 LANCZOS 와 같은 Lanczos3 를 직접 구현한다.

**Tech Stack:** 데스크톱 — Python 3.14, PyTorch 2.14+cpu, Pillow, numpy, tkinter. 웹 — ES 모듈 자바스크립트, HTML, CSS. **외부 라이브러리·번들러·패키지 매니저 없음.** 개발 중 단위 시험만 Node 24 로 돌린다.

**Spec:** [docs/superpowers/specs/2026-09-26-웹·데스크톱-버전-분리-design.md](../specs/2026-09-26-웹·데스크톱-버전-분리-design.md)

## Global Constraints

모든 과제의 요구사항에 아래가 암묵적으로 포함된다.

- **웹 런타임 의존성 0개.** `web_version/` 이 실행 시 받아 오는 것은 자기 폴더의 파일뿐이다. CDN, npm, 번들러, `package.json` 모두 금지. `도구/` 의 파이썬 스크립트만 예외이며 이것은 빌드 시점에만 돈다.
- **식별자와 주석은 전부 한글.** 파이썬 클래스·함수·변수·argparse 인자, 자바스크립트 함수·변수·클래스, CSS 클래스 이름까지. 예외는 세 군데뿐: `손글씨앱 실행.bat` 전체(ASCII 전용), DOM·표준 API 이름, `.github/workflows/pages.yml` 의 job·step `id`.
- **정규화 상수는 정확히 `평균 = 0.1307`, `표준편차 = 0.3081`.** `train.py`, `app.py`, `web_version/js/전처리.js` 세 곳에 같은 값으로 있어야 한다.
- **캔버스 한 변 280, 붓 굵기 22.** `app.py` 와 `web_version/js/그림판.js` 양쪽.
- **모델 구조는 바꾸지 않는다.** 합성곱(1→32, 3×3, 여백1) → 렐루 → 최대풀링2 → 합성곱(32→64, 3×3, 여백1) → 렐루 → 최대풀링2 → 평탄화 3136 → 전결합 128 → 렐루 → 전결합 10 → 로그소프트맥스. 재학습하지 않는다.
- **정확도 게이트: MNIST 평가 앞 200장에서 190/200 이상.** 데스크톱과 웹 양쪽.
- **인코딩:** `*.py`/`*.js`/`*.html`/`*.css`/`*.md` 는 UTF-8, `*.ps1` 은 UTF-8 **+ BOM**, `*.bat` 은 **ASCII 전용 + CRLF**. 파이썬 출력을 파이프로 받을 때는 `PYTHONIOENCODING=utf-8` 을 붙인다.
- **웹의 모든 경로는 상대 경로.** `/` 로 시작하는 절대 경로 금지. GitHub Pages 프로젝트 사이트(`사용자.github.io/저장소/`) 하위에서 동작해야 한다.
- **`web_version/모델/` 은 손으로 고치지 않는다.** `도구/가중치_내보내기.py` 의 결과물이다.

## 테스트 전략 (이 저장소에는 테스트 프레임워크가 없다)

기존 규약을 따른다. 저장소에 pytest, jest, 린터, 패키지 매니페스트가 없고 `CLAUDE.md` 가 "MNIST 평가 이미지를 전처리 경로에 통과시켜 확인한다" 를 검증 방법으로 정해 두고 있다. 새 프레임워크를 들이지 않는다.

- **영구적으로 남는 회귀 게이트:** `web_version/검증/검증.html` (브라우저) 과 `desktop_version/CLAUDE.md` 의 파이썬 스니펫. 둘 다 같은 200장에서 같은 점수를 내야 한다.
- **개발 중 단위 시험:** Node 24 로 돌리는 일회용 `.mjs` 스크립트. **스크래치패드에 두고 저장소에 커밋하지 않는다.** 프로젝트 파일은 ES 모듈이므로 확장자만 `.mjs` 로 바꿔 복사하면 Node 가 그대로 읽는다 (`web_version/` 에 `package.json` 을 만들지 않기 위한 방법이다).

각 과제의 시험 코드는 아래에 전문이 들어 있다. 스크래치패드 경로를 `$임시` 라고 쓴다.

```bash
임시="$(mktemp -d)"   # 또는 하네스가 알려 준 scratchpad 경로
cp web_version/js/전처리.js "$임시/전처리.mjs"    # 시험할 모듈을 이렇게 복사해 쓴다
```

## Review Focus

스펙이 암시하지만 200장 검증이 건드리지 않는 입력들이다. 각 줄의 시험은 아래 해당 과제 안에 들어 있다.

1. **아무것도 그리지 않고 인식을 누름** — `전처리()` 가 `null` 을 돌려주고, 화면은 "먼저 숫자를 써 주세요" 를 띄워야 한다. 예외가 나거나 빈 결과가 표시되면 안 된다. (과제 5, 과제 7)
2. **`file://` 로 HTML 을 직접 염** — `fetch` 가 막혀 모델을 못 읽는다. 무음 실패가 아니라 "웹 서버로 열어야 한다" 는 안내가 떠야 한다. (과제 7)
3. **점 하나만 찍거나 한 변이 1픽셀인 획** — 축소 비율이 20배까지 벌어진다. 0 크기 이미지나 `NaN` 이 나오면 안 된다. (과제 5)
4. **캔버스 밖으로 끌고 나가 버튼을 뗌** — 획이 끊긴 채 남거나 다음 클릭이 이어 그려지면 안 된다. `setPointerCapture` 로 포인터를 붙들어 둔다. (과제 7)
5. **가중치 파일이 모델 구조와 어긋남** (재학습 후 내보내기를 잊거나 구조를 바꾼 경우) — 오류 없이 엉뚱한 숫자를 내는 대신, 어느 텐서가 어떻게 다른지 말하고 멈춰야 한다. (과제 4)

### 과제 2: 가중치 내보내기 도구

**Files:**
- Create: `web_version/도구/가중치_내보내기.py`
- Modify: `.gitattributes` (`*.bin binary` 추가)
- 생성물: `web_version/모델/mnist_cnn.bin`, `web_version/모델/mnist_cnn.json`

**Interfaces:**
- Consumes: `desktop_version/mnist_cnn.pt`
- Produces: `mnist_cnn.json` 스키마 —
  `{"자료형":"float32","바이트순서":"little","본문파일":"mnist_cnn.bin","전체바이트":int,"텐서":[{"이름":str,"모양":[int],"시작바이트":int,"개수":int}]}`.
  과제 4 의 `가중치_불러오기()` 가 이 스키마를 읽는다.

- [ ] **Step 1: 스크립트를 쓴다**

`web_version/도구/가중치_내보내기.py` 전문:

```python
"""

그래서 텐서를 Float32 리틀엔디언 바이너리 한 덩어리로 이어 붙이고,
각 텐서의 이름·모양·시작 위치를 JSON 목록에 적어 둔다.

# 순서를 고정해야 바이너리가 재현 가능하다. js 쪽은 이름으로 찾으므로 순서에 의존하지 않는다.
텐서순서 = [
    "합성곱1.weight", "합성곱1.bias",
    "합성곱2.weight", "합성곱2.bias",
    "전결합1.weight", "전결합1.bias",
    "전결합2.weight", "전결합2.bias",
]


def 내보내기():
    if not 가중치파일.exists():
        print(f"가중치 파일이 없습니다: {가중치파일}", file=sys.stderr)
        print("먼저 desktop_version 에서 'python train.py' 를 실행해 주세요.", file=sys.stderr)
        return 1

    상태 = torch.load(가중치파일, map_location="cpu")

    빠진키 = [이름 for 이름 in 텐서순서 if 이름 not in 상태]
    if 빠진키:
        print(f"가중치에 다음 텐서가 없습니다: {빠진키}", file=sys.stderr)
        print("model.py 의 구조와 텐서순서 목록이 어긋난 것입니다.", file=sys.stderr)
        return 1

    남은키 = [이름 for 이름 in 상태 if 이름 not in 텐서순서]
    if 남은키:
        print(f"경고: 내보내지 않는 텐서가 있습니다: {남은키}", file=sys.stderr)

    내보낼폴더.mkdir(parents=True, exist_ok=True)
    이진파일 = 내보낼폴더 / "mnist_cnn.bin"
    목록파일 = 내보낼폴더 / "mnist_cnn.json"

    텐서목록 = []
    시작바이트 = 0
    with open(이진파일, "wb") as 파일:
        for 이름 in 텐서순서:
            값 = 상태[이름].detach().cpu().contiguous().to(torch.float32)
            평탄 = 값.flatten().tolist()
            # '<' 는 리틀엔디언, 'f' 는 4바이트 float. 자바스크립트 Float32Array 와 같다.
            파일.write(struct.pack(f"<{len(평탄)}f", *평탄))
            텐서목록.append({
                "이름": 이름,
                "모양": list(값.shape),
                "시작바이트": 시작바이트,
                "개수": len(평탄),
            })
            print(f"  {이름:<20} 모양={list(값.shape)} 개수={len(평탄)}")
            시작바이트 += len(평탄) * 4

    목록 = {
        "설명": "숫자인식CNN 가중치. 텐서를 C 순서로 평탄화해 이어 붙인 Float32 바이너리.",
        "자료형": "float32",
        "바이트순서": "little",
        "본문파일": "mnist_cnn.bin",
        "전체바이트": 시작바이트,
        "텐서": 텐서목록,
    }
    목록파일.write_text(json.dumps(목록, ensure_ascii=False, indent=2) + "\n", encoding="utf-8")

    print(f"\n{이진파일.name}  {시작바이트:,} 바이트 ({시작바이트 / 1024 / 1024:.2f} MB)")
    print(f"{목록파일.name}  텐서 {len(텐서목록)}개")
    return 0


if __name__ == "__main__":
    sys.exit(내보내기())
```

- Produces: `평가데이터.bin` 형식 (리틀엔디언) — `[0,4)` 개수 `uint32`, `[4, 4+개수)` 라벨 `uint8`, 그 뒤 이미지 `개수 × 784` 바이트(행 우선, 0=검정). 과제 6·8 이 읽는다.

브라우저는 torchvision 을 쓸 수 없으므로 평가 이미지를 미리 원시 바이트로 뽑아 둔다.

- [ ] **Step 1: 스크립트를 쓴다**

```python
"""
웹 버전 검증 페이지가 쓸 MNIST 평가 이미지를 바이너리로 뽑는다.

파일 형식 (리틀엔디언):
    [0..4)            개수 (uint32)
    [4..4+개수)       정답 라벨 (uint8 각 1바이트)
    [4+개수..)        이미지 (한 장당 28*28 = 784 바이트, 행 우선, 0=검정)
"""

import struct
import sys
from pathlib import Path

import numpy as np
from torchvision import datasets

기준폴더 = Path(__file__).resolve().parent.parent
저장소폴더 = 기준폴더.parent
데이터폴더 = 저장소폴더 / "desktop_version" / "data"
내보낼파일 = 기준폴더 / "검증" / "평가데이터.bin"

개수 = 200


def 만들기():
    if not 데이터폴더.exists():
        print(f"MNIST 데이터 폴더가 없습니다: {데이터폴더}", file=sys.stderr)
        print("desktop_version 에서 'python train.py' 를 한 번 실행하면 내려받습니다.",
              file=sys.stderr)
        return 1

    평가셋 = datasets.MNIST(str(데이터폴더), train=False, download=False)

    라벨들 = bytearray()
    이미지들 = bytearray()
    for 번호 in range(개수):
        원본, 정답 = 평가셋[번호]
        라벨들.append(정답)
        이미지들.extend(np.array(원본, dtype=np.uint8).tobytes())

    내보낼파일.parent.mkdir(parents=True, exist_ok=True)
    with open(내보낼파일, "wb") as 파일:
        파일.write(struct.pack("<I", 개수))
        파일.write(bytes(라벨들))
        파일.write(bytes(이미지들))

    크기 = 내보낼파일.stat().st_size
    print(f"{내보낼파일.name}  이미지 {개수}장, {크기:,} 바이트")
    print(f"앞쪽 라벨 20개: {list(라벨들[:20])}")
    return 0


if __name__ == "__main__":
    sys.exit(만들기())
```

**Interfaces:**

  - `가중치_불러오기(기준경로 = "모델") → Promise<{[이름]: {모양: number[], 값: Float32Array}}>`
  - `모양_검사(가중치) → void` (어긋나면 `Error` 를 던진다)
  - `기대하는모양` — 텐서 이름 → 모양 배열
  - `추론(입력: Float32Array(784), 가중치) → Float32Array(10)` — 합이 1인 확률

`신경망.js` 는 **브라우저 API 를 한 줄도 쓰지 않는다.** 특징맵은 1차원 `Float32Array` 에 `(채널, 행, 열)` 순서로 담고 색인은 `채널*(높이*너비) + 행*너비 + 열` 이다. PyTorch `flatten(1)` 과 같은 순서이며, 어긋나면 `전결합1` 가중치와 맞지 않아 **오류 없이 엉뚱한 답**이 나온다.

```javascript
// PyTorch 가 낸 로그확률과 자바스크립트 추론 결과를 대조한다.
import fs from "node:fs";
import { 추론 } from "./신경망.mjs";

const 뿌리 = process.argv[2];   // 저장소 뿌리 경로를 넘긴다

// Node 의 readFileSync 는 작은 파일을 내부 버퍼 풀에서 잘라 돌려주므로,
// .buffer 를 그대로 쓰면 byteOffset 이 0 이 아니어서 엉뚱한 바이트를 읽는다.
// 항상 byteOffset/byteLength 로 잘라 낸 뒤 타입 배열을 만든다.
function 실수배열로(경로) {
  const 버퍼 = fs.readFileSync(경로);
  return new Float32Array(버퍼.buffer.slice(버퍼.byteOffset, 버퍼.byteOffset + 버퍼.byteLength));
}

const 목록 = JSON.parse(fs.readFileSync(`${뿌리}/web_version/모델/mnist_cnn.json`, "utf8"));
const 본문 = fs.readFileSync(`${뿌리}/web_version/모델/mnist_cnn.bin`);
const 버퍼 = 본문.buffer.slice(본문.byteOffset, 본문.byteOffset + 본문.byteLength);
const 가중치 = {};
for (const 텐서 of 목록.텐서) {
  가중치[텐서.이름] = { 모양: 텐서.모양, 값: new Float32Array(버퍼, 텐서.시작바이트, 텐서.개수) };
}

const 기준입력 = 실수배열로(`${뿌리}/기준입력.bin`);
const 기준출력 = 실수배열로(`${뿌리}/기준출력.bin`);

let 최대오차 = 0;
for (let 장 = 0; 장 < 5; 장 += 1) {
  const 확률 = 추론(기준입력.slice(장 * 784, (장 + 1) * 784), 가중치);
  for (let 숫자 = 0; 숫자 < 10; 숫자 += 1) {
    // 파이썬 쪽은 로그확률이므로 exp 를 씌워 확률로 맞춘다.
    const 기대 = Math.exp(기준출력[장 * 10 + 숫자]);
    최대오차 = Math.max(최대오차, Math.abs(확률[숫자] - 기대));
  }
  const 합 = [...확률].reduce((ㄱ, ㄴ) => ㄱ + ㄴ, 0);
  if (Math.abs(합 - 1) > 1e-4) throw new Error(`${장}번 확률 합이 1이 아니다: ${합}`);
}
console.log(`PyTorch 대비 최대 오차: ${최대오차.toExponential(3)}`);
if (최대오차 > 1e-4) { console.log("실패: 오차가 너무 크다"); process.exit(1); }
console.log("통과");
```

```javascript
/**
 * 학습된 가중치를 내려받아 이름으로 찾아 쓸 수 있게 정리하는 모듈.
 * 형식은 도구/가중치_내보내기.py 가 만든다.
 */

/** 모델이 반드시 가지고 있어야 하는 텐서와 그 모양. model.py 의 구조와 같아야 한다. */
export const 기대하는모양 = {
  "합성곱1.weight": [32, 1, 3, 3],
  "합성곱1.bias": [32],
  "합성곱2.weight": [64, 32, 3, 3],
  "합성곱2.bias": [64],
  "전결합1.weight": [128, 3136],
  "전결합1.bias": [128],
  "전결합2.weight": [10, 128],
  "전결합2.bias": [10],
};

/**
 * 가중치를 내려받아 {텐서이름: {모양, 값}} 형태로 돌려준다.
 * 값은 Float32Array 이고 원본 텐서를 C 순서로 평탄화한 것이다.
 *
 * @param {string} 기준경로 모델 폴더의 상대 경로. 끝에 슬래시를 붙이지 않는다.
 */
export async function 가중치_불러오기(기준경로 = "모델") {
  const 목록응답 = await fetch(`${기준경로}/mnist_cnn.json`);
  if (!목록응답.ok) {
    throw new Error(
      `가중치 목록을 받지 못했습니다 (${목록응답.status}). ` +
      "도구/가중치_내보내기.py 를 먼저 실행했는지 확인해 주세요."
    );
  }
  const 목록 = await 목록응답.json();

  const 본문응답 = await fetch(`${기준경로}/${목록.본문파일}`);
  if (!본문응답.ok) {
    throw new Error(`가중치 본문을 받지 못했습니다 (${본문응답.status}).`);
  }
  const 버퍼 = await 본문응답.arrayBuffer();

  if (버퍼.byteLength !== 목록.전체바이트) {
    throw new Error(
      `가중치 크기가 목록과 다릅니다: 받은 ${버퍼.byteLength}바이트, ` +
      `기대한 ${목록.전체바이트}바이트`
    );
  }

  const 가중치 = {};
  for (const 텐서 of 목록.텐서) {
    // Float32Array 는 리틀엔디언 환경에서 바이트를 그대로 해석한다.
    가중치[텐서.이름] = {
      모양: 텐서.모양,
      값: new Float32Array(버퍼, 텐서.시작바이트, 텐서.개수),
    };
  }

  모양_검사(가중치);
  return 가중치;
}

/**
 * 받은 가중치가 신경망.js 가 가정하는 구조와 맞는지 확인한다.
 * 모양이 어긋난 채 추론하면 오류 없이 엉뚱한 숫자가 나오므로 여기서 먼저 거른다.
 */
export function 모양_검사(가중치) {
  for (const [이름, 기대] of Object.entries(기대하는모양)) {
    const 텐서 = 가중치[이름];
    if (!텐서) {
      throw new Error(`가중치에 '${이름}' 텐서가 없습니다.`);
    }
    const 실제 = 텐서.모양;
    if (실제.length !== 기대.length || 실제.some((값, 축) => 값 !== 기대[축])) {
      throw new Error(
        `'${이름}' 의 모양이 다릅니다: 받은 [${실제}], 기대한 [${기대}]. ` +
        "model.py 의 구조를 바꿨다면 가중치_내보내기.py 와 신경망.js 도 함께 고쳐야 합니다."
      );
    }
  }
}
```

```javascript
/**
 * 순수 자바스크립트 CNN 추론 엔진.
 * desktop_version/model.py 의 숫자인식CNN 순전파를 그대로 옮긴 것이다.
 *
 * 특징맵은 1차원 Float32Array 에 (채널, 행, 열) 순서로 담는다.
 *   색인 = 채널*(높이*너비) + 행*너비 + 열
 * PyTorch 의 flatten(1) 과 같은 순서이며, 어긋나면 전결합1 가중치와 맞지 않아
 * 오류 없이 엉뚱한 답이 나온다.
 *
 * 드롭아웃은 평가 모드에서 항등 함수이므로 구현하지 않는다.
 */

/** 2차원 합성곱. stride 는 1, 여백은 0 으로 채운다 (PyTorch 기본값과 같다). */
export function 합성곱(입력, 높이, 너비, 입력채널, 출력채널, 가중치, 편향, 커널, 여백) {
  const 면적 = 높이 * 너비;
  const 출력 = new Float32Array(출력채널 * 면적);

  for (let 출채 = 0; 출채 < 출력채널; 출채 += 1) {
    const 출력밑 = 출채 * 면적;
    const 편향값 = 편향[출채];

    for (let 행 = 0; 행 < 높이; 행 += 1) {
      for (let 열 = 0; 열 < 너비; 열 += 1) {
        let 합 = 편향값;

        for (let 입채 = 0; 입채 < 입력채널; 입채 += 1) {
          const 입력밑 = 입채 * 면적;
          const 커널밑 = (출채 * 입력채널 + 입채) * 커널 * 커널;

          for (let 커행 = 0; 커행 < 커널; 커행 += 1) {
            const 읽을행 = 행 + 커행 - 여백;
            if (읽을행 < 0 || 읽을행 >= 높이) continue;   // 여백은 0 이므로 건너뛴다

            for (let 커열 = 0; 커열 < 커널; 커열 += 1) {
              const 읽을열 = 열 + 커열 - 여백;
              if (읽을열 < 0 || 읽을열 >= 너비) continue;

              합 += 입력[입력밑 + 읽을행 * 너비 + 읽을열]
                  * 가중치[커널밑 + 커행 * 커널 + 커열];
            }
          }
        }
        출력[출력밑 + 행 * 너비 + 열] = 합;
      }
    }
  }
  return 출력;
}

/** 제자리에서 렐루를 적용한다 (음수를 0 으로). */
export function 렐루(배열) {
  for (let 색인 = 0; 색인 < 배열.length; 색인 += 1) {
    if (배열[색인] < 0) 배열[색인] = 0;
  }
  return 배열;
}

/** 최대풀링. 창 크기와 보폭이 같다. 홀수 크기는 PyTorch 처럼 남는 줄을 버린다. */
export function 최대풀링(입력, 채널, 높이, 너비, 창) {
  const 새높이 = Math.floor(높이 / 창);
  const 새너비 = Math.floor(너비 / 창);
  const 출력 = new Float32Array(채널 * 새높이 * 새너비);

  for (let 채 = 0; 채 < 채널; 채 += 1) {
    const 입력밑 = 채 * 높이 * 너비;
    const 출력밑 = 채 * 새높이 * 새너비;

    for (let 행 = 0; 행 < 새높이; 행 += 1) {
      for (let 열 = 0; 열 < 새너비; 열 += 1) {
        let 최대 = -Infinity;
        for (let 창행 = 0; 창행 < 창; 창행 += 1) {
          for (let 창열 = 0; 창열 < 창; 창열 += 1) {
            const 값 = 입력[입력밑 + (행 * 창 + 창행) * 너비 + (열 * 창 + 창열)];
            if (값 > 최대) 최대 = 값;
          }
        }
        출력[출력밑 + 행 * 새너비 + 열] = 최대;
      }
    }
  }
  return 출력;
}

/** 완전연결층. PyTorch Linear 와 같이 가중치는 (출력수, 입력수) 순서다. */
export function 전결합(입력, 가중치, 편향, 입력수, 출력수) {
  const 출력 = new Float32Array(출력수);
  for (let 출 = 0; 출 < 출력수; 출 += 1) {
    const 밑 = 출 * 입력수;
    let 합 = 편향[출];
    for (let 입 = 0; 입 < 입력수; 입 += 1) {
      합 += 가중치[밑 + 입] * 입력[입];
    }
    출력[출] = 합;
  }
  return 출력;
}

/** 로그 소프트맥스. 최댓값을 먼저 빼서 exp 가 넘치지 않게 한다. */
export function 로그소프트맥스(배열) {
  let 최대 = -Infinity;
  for (const 값 of 배열) if (값 > 최대) 최대 = 값;

  let 합 = 0;
  for (const 값 of 배열) 합 += Math.exp(값 - 최대);

  const 로그합 = Math.log(합);
  const 출력 = new Float32Array(배열.length);
  for (let 색인 = 0; 색인 < 배열.length; 색인 += 1) {
    출력[색인] = 배열[색인] - 최대 - 로그합;
  }
  return 출력;
}

/**
 * 28x28 정규화된 입력 하나를 넣어 0~9 각각의 확률을 얻는다.
 *
 * @param {Float32Array} 입력 길이 784. (값/255 - 평균) / 표준편차 로 정규화된 상태
 * @param {object} 가중치 가중치.js 의 가중치_불러오기() 결과
 * @returns {Float32Array} 길이 10, 합이 1인 확률
 */
export function 추론(입력, 가중치) {
  if (입력.length !== 28 * 28) {
    throw new Error(`입력 길이가 784 가 아닙니다: ${입력.length}`);
  }

  // 합성곱1 → 렐루 → 최대풀링 : (1,28,28) → (32,14,14)
  let 특징 = 합성곱(입력, 28, 28, 1, 32,
                    가중치["합성곱1.weight"].값, 가중치["합성곱1.bias"].값, 3, 1);
  렐루(특징);
  특징 = 최대풀링(특징, 32, 28, 28, 2);

  // 합성곱2 → 렐루 → 최대풀링 : (32,14,14) → (64,7,7)
  특징 = 합성곱(특징, 14, 14, 32, 64,
                가중치["합성곱2.weight"].값, 가중치["합성곱2.bias"].값, 3, 1);
  렐루(특징);
  특징 = 최대풀링(특징, 64, 14, 14, 2);

  // 특징은 이미 (채널, 행, 열) 순서로 평탄하므로 따로 펼칠 필요가 없다. 길이 3136.
  let 출력 = 전결합(특징, 가중치["전결합1.weight"].값, 가중치["전결합1.bias"].값, 3136, 128);
  렐루(출력);
  출력 = 전결합(출력, 가중치["전결합2.weight"].값, 가중치["전결합2.bias"].값, 128, 10);

  const 로그확률 = 로그소프트맥스(출력);
  const 확률 = new Float32Array(10);
  for (let 숫자 = 0; 숫자 < 10; 숫자 += 1) 확률[숫자] = Math.exp(로그확률[숫자]);
  return 확률;
}
```

### 과제 5: 전처리 (Lanczos3 포함)

**Files:**
- Create: `web_version/js/전처리.js`

**Interfaces:**
- Consumes: 없음 (순수 함수 묶음)
- Produces:
  - `전처리(회색: Uint8Array, 너비, 높이) → {텐서: Float32Array(784), 이십팔: Uint8Array(784)} | null`
  - `란초스크기변경(픽셀: Uint8Array, 너비, 높이, 새너비, 새높이) → Uint8Array`
  - `경계상자(픽셀, 너비, 높이) → [왼, 위, 오른, 아래] | null` (오른·아래는 포함하지 않음)
  - `무게중심이동(도화지: Uint8Array(784)) → Uint8Array(784)`
  - `회색으로(RGBA: Uint8ClampedArray) → Uint8Array`
  - `파이썬반올림(값) → number`
  - `평균 = 0.1307`, `표준편차 = 0.3081`

**이 파일이 인식률의 핵심이다.** `app.py` 의 `전처리()` 와 같은 6단계를 같은 순서로 밟는다.

축소를 canvas `drawImage` 에 맡기지 않는 이유: `drawImage` 의 리샘플링은 명세에 정해져 있지 않아 브라우저마다 결과가 다르고 PIL 의 LANCZOS 와도 어긋난다. PIL `Image.resize` 의 계산 절차를 그대로 구현한다.

`파이썬반올림()` 이 따로 필요한 이유: 자바스크립트 `Math.round` 는 0.5 를 항상 위로 올리지만 파이썬 `round()` 는 짝수 쪽으로 보낸다(은행가 반올림). 축소 크기와 무게중심 이동량에서 1픽셀이 밀린다.

```javascript
// Node 의 readFileSync 는 작은 파일을 내부 버퍼 풀에서 잘라 돌려주므로,
// .buffer 를 그대로 쓰면 byteOffset 이 0 이 아니어서 엉뚱한 바이트를 읽는다.
// 항상 byteOffset/byteLength 로 잘라 낸 뒤 타입 배열을 만든다.
function 실수배열로(경로) {
  const 버퍼 = fs.readFileSync(경로);
  return new Float32Array(버퍼.buffer.slice(버퍼.byteOffset, 버퍼.byteOffset + 버퍼.byteLength));
}

const 개수 = 평가.readUInt32LE(0);

const 기준 = 실수배열로(`${뿌리}/전처리_기준.bin`);

let 최대오차 = 0;
let 다른픽셀 = 0;
for (let 번호 = 0; 번호 < 개수; 번호 += 1) {
  const 원본 = new Uint8Array(평가.subarray(이미지밑 + 번호 * 784, 이미지밑 + (번호 + 1) * 784));
  const 확대 = 란초스크기변경(원본, 28, 28, 280, 280);

  for (let 색인 = 0; 색인 < 784; 색인 += 1) {

    if (차이 > 1e-6) 다른픽셀 += 1;
    if (차이 > 최대오차) 최대오차 = 차이;
  }
}
```

```javascript
export function 파이썬반올림(값) {
  const 내림 = Math.floor(값);
  const 나머지 = 값 - 내림;

  return 내림 % 2 === 0 ? 내림 : 내림 + 1;
```

Lanczos3 리샘플링 (PIL `Image.resize` 의 LANCZOS 와 같은 계산):

```javascript
const 지지 = 3;   // Lanczos3 의 지지 반경

function 싱크(값) {
  if (값 === 0) return 1;
  const 라디안 = Math.PI * 값;
  return Math.sin(라디안) / 라디안;
}

function 란초스(값) {
  if (값 >= -지지 && 값 < 지지) return 싱크(값) * 싱크(값 / 지지);
  return 0;
}

/**
 * 한 축의 출력 픽셀마다 "입력 어디서부터, 어떤 가중치로 섞을지" 를 미리 계산한다.
 * 축소할 때는 필터를 배율만큼 넓혀 여러 입력 픽셀을 평균하게 만든다(안티에일리어싱).
 * 이 폭 조정이 없으면 계단 현상이 생겨 얇은 획이 사라진다.
 */
function 계수계산(입력크기, 출력크기) {
  const 배율 = 입력크기 / 출력크기;
  const 필터배율 = Math.max(1, 배율);
  const 지지폭 = 지지 * 필터배율;
  const 목록 = [];

  for (let 출 = 0; 출 < 출력크기; 출 += 1) {
    const 중심 = (출 + 0.5) * 배율;
    let 시작 = Math.floor(중심 - 지지폭);
    let 끝 = Math.ceil(중심 + 지지폭);
    if (시작 < 0) 시작 = 0;
    if (끝 > 입력크기) 끝 = 입력크기;

    const 계수 = new Float64Array(끝 - 시작);
    let 합 = 0;
    for (let 칸 = 0; 칸 < 계수.length; 칸 += 1) {
      const 가중 = 란초스((칸 + 시작 - 중심 + 0.5) / 필터배율);
      계수[칸] = 가중;
      합 += 가중;
    }
    // 가중치 합이 1이 되도록 정규화해야 밝기가 유지된다.
    if (합 !== 0) {
      for (let 칸 = 0; 칸 < 계수.length; 칸 += 1) 계수[칸] /= 합;
    }
    목록.push({ 시작, 계수 });
  }
  return 목록;
}

/** 소수 결과를 0~255 정수로 되돌린다. PIL 도 각 축을 지나고 나서 같은 처리를 한다. */
function 자르기(값) {
  const 정수 = Math.round(값);
  if (정수 < 0) return 0;
  if (정수 > 255) return 255;
  return 정수;
}

function 가로변환(픽셀, 너비, 높이, 새너비) {
  const 계수목록 = 계수계산(너비, 새너비);
  const 출력 = new Uint8Array(새너비 * 높이);
  for (let 행 = 0; 행 < 높이; 행 += 1) {
    const 입력밑 = 행 * 너비;
    const 출력밑 = 행 * 새너비;
    for (let 열 = 0; 열 < 새너비; 열 += 1) {
      const { 시작, 계수 } = 계수목록[열];
      let 합 = 0;
      for (let 칸 = 0; 칸 < 계수.length; 칸 += 1) {
        합 += 픽셀[입력밑 + 시작 + 칸] * 계수[칸];
      }
      출력[출력밑 + 열] = 자르기(합);
    }
  }
  return 출력;
}

function 세로변환(픽셀, 너비, 높이, 새높이) {
  const 계수목록 = 계수계산(높이, 새높이);
  const 출력 = new Uint8Array(너비 * 새높이);
  for (let 행 = 0; 행 < 새높이; 행 += 1) {
    const { 시작, 계수 } = 계수목록[행];
    const 출력밑 = 행 * 너비;
    for (let 열 = 0; 열 < 너비; 열 += 1) {
      let 합 = 0;
      for (let 칸 = 0; 칸 < 계수.length; 칸 += 1) {
        합 += 픽셀[(시작 + 칸) * 너비 + 열] * 계수[칸];
      }
      출력[출력밑 + 열] = 자르기(합);
    }
  }
  return 출력;
}

/**
 * 흑백 이미지의 크기를 Lanczos3 으로 바꾼다. 가로 → 세로 순서로 분리 적용한다.
 * 확대·축소 모두 쓸 수 있다 (검증 페이지는 28x28 을 280x280 으로 확대하는 데 쓴다).
 */
export function 란초스크기변경(픽셀, 너비, 높이, 새너비, 새높이) {
  let 현재 = 픽셀;
  let 현재너비 = 너비;
  if (새너비 !== 너비) {
    현재 = 가로변환(현재, 현재너비, 높이, 새너비);
    현재너비 = 새너비;
  }
  if (새높이 !== 높이) {
    현재 = 세로변환(현재, 현재너비, 높이, 새높이);
  }
  // 크기가 그대로면 호출한 쪽이 고쳐도 안전하도록 복사해 돌려준다.
  return 현재 === 픽셀 ? Uint8Array.from(픽셀) : 현재;
}
```

```javascript
/**
 * 0 이 아닌 픽셀이 차지하는 사각 범위. PIL 의 getbbox() 와 같다.
 * 오른쪽·아래는 포함하지 않는 좌표다. 아무것도 없으면 null.
 */
export function 경계상자(픽셀, 너비, 높이) {
  let 왼 = 너비, 위 = 높이, 오른 = -1, 아래 = -1;

  for (let 행 = 0; 행 < 높이; 행 += 1) {
    const 밑 = 행 * 너비;
    for (let 열 = 0; 열 < 너비; 열 += 1) {
      if (픽셀[밑 + 열] !== 0) {
        if (열 < 왼) 왼 = 열;
        if (열 > 오른) 오른 = 열;
        if (행 < 위) 위 = 행;
        if (행 > 아래) 아래 = 행;
      }
    }
  }
  if (오른 < 0) return null;
  return [왼, 위, 오른 + 1, 아래 + 1];
}

function 잘라내기(픽셀, 너비, 왼, 위, 폭, 높) {
  const 출력 = new Uint8Array(폭 * 높);
  for (let 행 = 0; 행 < 높; 행 += 1) {
    출력.set(픽셀.subarray((위 + 행) * 너비 + 왼, (위 + 행) * 너비 + 왼 + 폭), 행 * 폭);
  }
  return 출력;
}

/**
 * 픽셀 값의 무게중심을 28x28 의 정확한 중앙(13.5, 13.5)으로 평행 이동한다.
 * 이동량은 정수로 반올림하며 빈 자리는 0 으로 채운다.
 * (PIL 의 Image.AFFINE + 기본 NEAREST 보간과 같은 결과)
 */
export function 무게중심이동(도화지) {
  let 총합 = 0, 가로합 = 0, 세로합 = 0;
  for (let 행 = 0; 행 < 28; 행 += 1) {
    for (let 열 = 0; 열 < 28; 열 += 1) {
      const 값 = 도화지[행 * 28 + 열];
      if (값 === 0) continue;
      총합 += 값;
      가로합 += 열 * 값;
      세로합 += 행 * 값;
    }
  }
  if (총합 <= 0) return 도화지;

  const 이동x = 파이썬반올림(13.5 - 가로합 / 총합);
  const 이동y = 파이썬반올림(13.5 - 세로합 / 총합);
  if (이동x === 0 && 이동y === 0) return 도화지;

  const 출력 = new Uint8Array(28 * 28);
  for (let 행 = 0; 행 < 28; 행 += 1) {
    const 원행 = 행 - 이동y;
    if (원행 < 0 || 원행 >= 28) continue;
    for (let 열 = 0; 열 < 28; 열 += 1) {
      const 원열 = 열 - 이동x;
      if (원열 < 0 || 원열 >= 28) continue;
      출력[행 * 28 + 열] = 도화지[원행 * 28 + 원열];
    }
  }
  return 출력;
}

/**
 * canvas 의 getImageData().data (RGBA) 에서 흑백 값만 뽑는다.
 * 그림판은 검은 배경에 흰 붓으로만 그리므로 R=G=B 이고 알파는 255 다.
 */
export function 회색으로(RGBA) {
  const 출력 = new Uint8Array(RGBA.length / 4);
  for (let 색인 = 0; 색인 < 출력.length; 색인 += 1) {
    출력[색인] = RGBA[색인 * 4];
  }
  return 출력;
}

/**
 * 그린 그림을 모델 입력으로 바꾼다. 아무것도 그리지 않았으면 null.
 *
 * @param {Uint8Array} 회색 흑백 픽셀 (0 = 배경, 255 = 획)
 * @returns {?{텐서: Float32Array, 이십팔: Uint8Array}}
 */
export function 전처리(회색, 너비, 높이) {
  const 경계 = 경계상자(회색, 너비, 높이);
  if (경계 === null) return null;

  const [왼, 위, 오른, 아래] = 경계;
  const 폭 = 오른 - 왼;
  const 높 = 아래 - 위;
  const 잘라낸 = 잘라내기(회색, 너비, 왼, 위, 폭, 높);

  // 긴 변이 20px 이 되도록 비율을 유지하며 축소한다.
  const 비율 = 20 / Math.max(폭, 높);
  const 새폭 = Math.max(1, 파이썬반올림(폭 * 비율));
  const 새높 = Math.max(1, 파이썬반올림(높 * 비율));
  const 축소 = 란초스크기변경(잘라낸, 폭, 높, 새폭, 새높);

  // 28x28 검은 도화지 한가운데에 붙인다.
  const 도화지 = new Uint8Array(28 * 28);
  const 왼여백 = Math.floor((28 - 새폭) / 2);
  const 위여백 = Math.floor((28 - 새높) / 2);
  for (let 행 = 0; 행 < 새높; 행 += 1) {
    도화지.set(축소.subarray(행 * 새폭, (행 + 1) * 새폭), (위여백 + 행) * 28 + 왼여백);
  }

  const 이십팔 = 무게중심이동(도화지);

  // 0~255 를 0~1 로 바꾼 뒤 학습 때와 똑같이 정규화한다.
  const 텐서 = new Float32Array(28 * 28);
  for (let 색인 = 0; 색인 < 텐서.length; 색인 += 1) {
    텐서[색인] = (이십팔[색인] / 255 - 평균) / 표준편차;
  }
  return { 텐서, 이십팔 };
}
```

### 과제 7: 그림판과 화면

**Files:**

- Create: `web_version/js/앱.js`
- Create: `web_version/index.html`
- Create: `web_version/스타일.css`

**Interfaces:**
- Consumes: `가중치_불러오기`, `추론`, `전처리`, `회색으로`
- Produces: `캔버스크기 = 280`, `펜굵기 = 22`, `class 그림판` — 생성자 `(캔버스요소, {붓뗐을때})`, 메서드 `지우기()`, `회색픽셀() → Uint8Array(280*280)`

**데스크톱과 다른 점 하나:** 데스크톱은 tkinter Canvas 에서 픽셀을 되읽을 수 없어 PIL 이미지에 이중으로 그렸다. 웹은 `getImageData` 로 읽을 수 있으므로 **캔버스 하나만 쓴다.** 데스크톱 코드를 참고하다가 이중 그리기를 따라 옮기지 않는다.

**캔버스 내부 해상도는 항상 280×280.** CSS 로 표시 크기만 줄인다. 화면 크기에 따라 전처리 결과가 달라지면 안 된다. 좌표 변환은 `getBoundingClientRect` 비율로 한다.

- [ ] **Step 1: `web_version/js/그림판.js` 를 쓴다**

```javascript
/**
 * 마우스·터치·펜으로 숫자를 쓰는 그림판.
 *
 * 포인터 이벤트를 쓰므로 마우스·손가락·펜이 모두 같은 경로로 처리된다.
 * 데스크톱과 달리 캔버스 하나만 쓴다 (getImageData 로 픽셀을 되읽을 수 있다).
 */

import { 회색으로 } from "./전처리.js";

/** 캔버스 한 변의 픽셀 수. app.py 의 캔버스크기 와 같아야 한다 (28의 10배). */
export const 캔버스크기 = 280;

/** 붓 굵기. MNIST 글씨 두께와 비슷해지도록 잡은 값. app.py 의 펜굵기 와 같다. */
export const 펜굵기 = 22;

export class 그림판 {
  /**
   * @param {HTMLCanvasElement} 캔버스요소
   * @param {{붓뗐을때?: () => void}} 설정 붓뗐을때 — 획을 끝냈을 때 부를 함수
   */
  constructor(캔버스요소, { 붓뗐을때 } = {}) {
    // 화면에 보이는 크기는 CSS 가 정하고, 내부 해상도는 280x280 으로 고정한다.
    캔버스요소.width = 캔버스크기;
    캔버스요소.height = 캔버스크기;

    this.캔버스 = 캔버스요소;
    this.맥락 = 캔버스요소.getContext("2d", { willReadFrequently: true });
    this.붓뗐을때 = 붓뗐을때;
    this.이전좌표 = null;
    this.그린적있음 = false;

    this.맥락.lineCap = "round";    // tkinter 의 capstyle=ROUND 와 같은 모양
    this.맥락.lineJoin = "round";
    this.맥락.lineWidth = 펜굵기;
    this.맥락.strokeStyle = "white";
    this.맥락.fillStyle = "white";

    this.지우기();
    this.이벤트연결();
  }

  이벤트연결() {
    const 캔버스 = this.캔버스;
    캔버스.addEventListener("pointerdown", (이벤트) => {
      이벤트.preventDefault();
      // 포인터를 캔버스에 붙들어 두면 캔버스 밖으로 나가도 이벤트가 계속 온다.
      캔버스.setPointerCapture(이벤트.pointerId);
      this.그리기시작(this.좌표변환(이벤트));
    });
    캔버스.addEventListener("pointermove", (이벤트) => {
      if (this.이전좌표 === null) return;
      이벤트.preventDefault();
      this.그리는중(this.좌표변환(이벤트));
    });
    for (const 이름 of ["pointerup", "pointercancel"]) {
      캔버스.addEventListener(이름, (이벤트) => {
        if (this.이전좌표 === null) return;
        이벤트.preventDefault();
        this.그리기끝();
      });
    }
    // 길게 누를 때 뜨는 컨텍스트 메뉴를 막는다 (모바일에서 방해가 된다).
    캔버스.addEventListener("contextmenu", (이벤트) => 이벤트.preventDefault());
  }

  /** 화면 좌표를 캔버스 내부 좌표(0~280)로 바꾼다. */
  좌표변환(이벤트) {
    const 사각 = this.캔버스.getBoundingClientRect();
    return {
      x: ((이벤트.clientX - 사각.left) / 사각.width) * 캔버스크기,
      y: ((이벤트.clientY - 사각.top) / 사각.height) * 캔버스크기,
    };
  }

  그리기시작(좌표) {
    this.이전좌표 = 좌표;
    this.그린적있음 = true;
    // 점만 찍고 떼는 경우에도 획이 남도록 원을 하나 그린다 (app.py 도 같다).
    this.맥락.beginPath();
    this.맥락.arc(좌표.x, 좌표.y, 펜굵기 / 2, 0, Math.PI * 2);
    this.맥락.fill();
  }

  그리는중(좌표) {
    this.맥락.beginPath();
    this.맥락.moveTo(this.이전좌표.x, this.이전좌표.y);
    this.맥락.lineTo(좌표.x, 좌표.y);
    this.맥락.stroke();
    this.이전좌표 = 좌표;
  }

  그리기끝() {
    this.이전좌표 = null;
    if (this.붓뗐을때) this.붓뗐을때();
  }

  /** 캔버스를 검게 비운다. */
  지우기() {
    this.맥락.fillStyle = "black";
    this.맥락.fillRect(0, 0, 캔버스크기, 캔버스크기);
    this.맥락.fillStyle = "white";
    this.이전좌표 = null;
    this.그린적있음 = false;
  }

  /** 현재 그림을 흑백 픽셀 배열로 돌려준다 (0 = 배경, 255 = 획). */
  회색픽셀() {
    return 회색으로(this.맥락.getImageData(0, 0, 캔버스크기, 캔버스크기).data);
  }
}
```

- [ ] **Step 4: `web_version/js/앱.js` 를 쓴다**

```javascript
/**
 * 화면과 추론을 잇는 조립 모듈.
 * desktop_version/app.py 의 손글씨앱 클래스가 하던 일과 같다.
 */

import { 가중치_불러오기 } from "./가중치.js";
import { 추론 } from "./신경망.js";
import { 전처리 } from "./전처리.js";
import { 그림판, 캔버스크기 } from "./그림판.js";

const 요소 = {
  그림판: document.getElementById("그림판"),
  인식버튼: document.getElementById("인식버튼"),
  지우기버튼: document.getElementById("지우기버튼"),
  결과숫자: document.getElementById("결과숫자"),
  확신도: document.getElementById("확신도"),
  확률표: document.getElementById("확률표"),
  오류: document.getElementById("오류"),
};

/** 확률 막대 10줄의 DOM 을 만들고 {바탕, 막대, 값} 목록을 돌려준다. */
function 확률표_만들기(담을곳) {
  const 줄들 = [];
  for (let 숫자 = 0; 숫자 < 10; 숫자 += 1) {
    const 이름표 = document.createElement("span");
    이름표.className = "확률숫자";
    이름표.textContent = String(숫자);

    const 바탕 = document.createElement("div");
    바탕.className = "막대바탕";
    // 스크린 리더가 값을 읽을 수 있도록 진행 막대로 알린다.
    바탕.setAttribute("role", "progressbar");
    바탕.setAttribute("aria-label", `숫자 ${숫자} 의 확률`);
    바탕.setAttribute("aria-valuemin", "0");
    바탕.setAttribute("aria-valuemax", "100");
    바탕.setAttribute("aria-valuenow", "0");

    const 막대 = document.createElement("div");
    막대.className = "막대";
    바탕.appendChild(막대);

    const 값 = document.createElement("span");
    값.className = "확률값";
    값.textContent = "0.0%";

    담을곳.append(이름표, 바탕, 값);
    줄들.push({ 바탕, 막대, 값 });
  }
  return 줄들;
}

function 확률표_갱신(줄들, 확률, 예측숫자) {
  for (let 숫자 = 0; 숫자 < 10; 숫자 += 1) {
    const 백분율 = 확률[숫자] * 100;
    줄들[숫자].막대.style.width = `${백분율}%`;
    줄들[숫자].막대.classList.toggle("최고", 숫자 === 예측숫자);
    줄들[숫자].값.textContent = `${백분율.toFixed(1)}%`;
    줄들[숫자].바탕.setAttribute("aria-valuenow", 백분율.toFixed(1));
  }
}

function 확률표_비우기(줄들) {
  for (const 줄 of 줄들) {
    줄.막대.style.width = "0";
    줄.막대.classList.remove("최고");
    줄.값.textContent = "0.0%";
    줄.바탕.setAttribute("aria-valuenow", "0");
  }
}

function 오류보이기(내용) {
  요소.오류.textContent = 내용;
  요소.오류.hidden = false;
}

async function 시작() {
  const 확률줄들 = 확률표_만들기(요소.확률표);

  // 가중치를 받기 전에는 인식할 수 없으므로 버튼을 잠가 둔다.
  요소.인식버튼.disabled = true;

  let 가중치;
  try {
    가중치 = await 가중치_불러오기("모델");
  } catch (오류) {
    요소.확신도.textContent = "모델을 불러오지 못했습니다";
    오류보이기(
      `모델을 불러오지 못했습니다.\n${오류.message}\n\n` +
      "파일을 직접 열지 않고 (file:// 에서는 fetch 가 막힙니다) " +
      "간단한 웹 서버로 열어야 합니다. 예: python -m http.server"
    );
    return;
  }

  const 판 = new 그림판(요소.그림판, { 붓뗐을때: () => 인식하기() });

  요소.인식버튼.disabled = false;
  요소.확신도.textContent = "숫자를 써 주세요";

  function 인식하기() {
    const 결과 = 전처리(판.회색픽셀(), 캔버스크기, 캔버스크기);
    if (결과 === null) {
      요소.확신도.textContent = "먼저 숫자를 써 주세요";
      return;
    }

    const 확률 = 추론(결과.텐서, 가중치);
    let 예측숫자 = 0;
    for (let 숫자 = 1; 숫자 < 10; 숫자 += 1) {
      if (확률[숫자] > 확률[예측숫자]) 예측숫자 = 숫자;
    }

    요소.결과숫자.textContent = String(예측숫자);
    요소.확신도.textContent = `확신도 ${(확률[예측숫자] * 100).toFixed(1)}%`;
    확률표_갱신(확률줄들, 확률, 예측숫자);
  }

  function 지우기() {
    판.지우기();
    요소.결과숫자.textContent = "?";
    요소.확신도.textContent = "숫자를 써 주세요";
    확률표_비우기(확률줄들);
  }

  요소.인식버튼.addEventListener("click", 인식하기);
  요소.지우기버튼.addEventListener("click", 지우기);
}

시작().catch((오류) => {
  오류보이기(`예기치 못한 오류가 일어났습니다.\n${오류.message}`);
});
```

```javascript

import { 추론 } from "../js/신경망.js";
import { 전처리, 란초스크기변경 } from "../js/전처리.js";

const 합격기준 = 190;

async function 검증() {

  const 응답 = await fetch("평가데이터.bin");

      "도구/평가데이터_만들기.py 를 먼저 실행해 주세요."
    );
  }
  const 버퍼 = await 응답.arrayBuffer();
  const 개수 = new DataView(버퍼).getUint32(0, true);
  const 라벨들 = new Uint8Array(버퍼, 4, 개수);
  const 이미지밑 = 4 + 개수;

  let 맞힘 = 0;
  const 틀린것 = [];
  const 시작시각 = performance.now();

  for (let 번호 = 0; 번호 < 개수; 번호 += 1) {

    const 결과 = 전처리(란초스크기변경(원본, 28, 28, 280, 280), 280, 280);
    if (결과 === null) {
      틀린것.push({ 번호, 정답: 라벨들[번호], 예측: "빈그림", 확신도: 0, 이십팔: null });
      continue;
    }
    const 확률 = 추론(결과.텐서, 가중치);
    let 예측 = 0;
    for (let 숫자 = 1; 숫자 < 10; 숫자 += 1) if (확률[숫자] > 확률[예측]) 예측 = 숫자;

    if (예측 === 라벨들[번호]) 맞힘 += 1;
    else 틀린것.push({
      번호, 정답: 라벨들[번호], 예측,
      확신도: 확률[예측] * 100, 이십팔: 결과.이십팔,
    });
  }

  const 걸린시간 = performance.now() - 시작시각;
  const 합격 = 맞힘 >= 합격기준;
  // 점수, 정확도, 한 장당 소요 시간, 그리고 틀린 것들의 표를 화면에 그린다.
  // 틀린 항목은 결과.이십팔 (28x28 흑백) 을 캔버스로 확대해 함께 보여 준다.
}
```

점수는 `${맞힘} / ${개수} ${합격 ? "합격" : "불합격"}` 으로 크게 띄우고, 합격이면 초록(`#157347`), 불합격이면 빨강(`#b02a1a`) 으로 표시한다.
