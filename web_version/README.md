# 손글씨 숫자 인식기 — 웹 버전

브라우저에서 마우스나 손가락으로 쓴 숫자를 바로 인식합니다.
**외부 라이브러리를 하나도 쓰지 않고** 순수 자바스크립트로 추론합니다.

그림은 서버로 가지 않습니다. 모든 계산이 브라우저 안에서 끝납니다.

## 실행

`file://` 로 HTML 을 직접 열면 `fetch` 가 막혀 모델을 읽지 못합니다.
간단한 웹 서버로 띄워야 합니다.

```bash
python -m http.server 8765 --directory web_version
```

그다음 <http://localhost:8765/> 에 접속합니다.

## 무엇이 들어 있나

| 경로 | 설명 |
|---|---|
| `index.html`, `스타일.css` | 화면 |
| `js/신경망.js` | CNN 순전파. 합성곱·최대풀링·전결합·로그소프트맥스를 직접 구현 |
| `js/전처리.js` | 그림 → 28×28 MNIST 형식 변환. Lanczos3 리샘플링 포함 |
| `js/그림판.js` | 캔버스 입력. 포인터 이벤트라 마우스·터치·펜이 모두 같은 경로 |
| `js/가중치.js` | 가중치 파일을 받아 이름으로 찾아 쓰게 정리 |
| `js/앱.js` | 위 넷을 조립 |
| `모델/mnist_cnn.bin` | Float32 가중치 (1.61MB) |
| `모델/mnist_cnn.json` | 텐서 이름·모양·오프셋 목록 |
| `도구/` | `.pt` → `.bin` 변환, 검증용 평가 데이터 추출 (파이썬) |
| `검증/검증.html` | 정확도 측정 페이지 |

## 정확도

MNIST 평가 이미지 200장 기준 **199/200 (99.5%)** 입니다.
데스크톱 버전도 같은 200장에서 199/200 이고, 틀리는 이미지(43번, 2를 4로 봄)까지 같습니다.

직접 확인하려면 서버를 띄운 뒤 <http://localhost:8765/검증/검증.html> 을 엽니다.

## 데스크톱 버전과 무엇이 같고 다른가

| | 웹 | 데스크톱 |
|---|---|---|
| 추론 | 순수 자바스크립트 | PyTorch |
| 가중치 | 같은 값 (`.bin` 으로 변환) | `mnist_cnn.pt` |
| 전처리 | 같은 6단계 | 같은 6단계 |
| 입력 | 마우스 · 터치 · 펜 | 마우스 |
| 학습 | 없음 | `train.py` |
| 설치 | 필요 없음 | Python + PyTorch |

## 가중치를 다시 내보내려면

`desktop_version` 에서 재학습했거나 모델 구조를 바꿨을 때만 필요합니다.

```bash
python web_version/도구/가중치_내보내기.py
```

## GitHub Pages 배포

`.github/workflows/pages.yml` 이 `main` 브랜치의 `web_version/` 변경을 감지해
자동으로 올립니다. 처음 한 번은 저장소 설정을 바꿔 주어야 합니다.

**Settings → Pages → Build and deployment → Source** 를 `GitHub Actions` 로 지정하세요.

빌드 단계는 없습니다. 이 폴더의 파일이 그대로 사이트가 됩니다.

## 왜 축소 필터를 직접 구현했나

캔버스의 `drawImage` 로 크기를 줄이면 간단하지만, 리샘플링 알고리즘이 명세에
정해져 있지 않아 **브라우저마다 결과가 다릅니다.** 데스크톱 버전이 쓰는 PIL 의
LANCZOS 와도 어긋나서, 같은 그림인데 웹과 데스크톱의 인식 결과가 달라집니다.

그래서 `js/전처리.js` 안에 Lanczos3 리샘플링을 직접 구현했습니다.
그 결과 두 구현의 전처리 출력은 156,800 픽셀 중 10 픽셀만 1/255 만큼 다릅니다.
