# CLAUDE.md (web_version)

순수 자바스크립트로 MNIST 손글씨 숫자를 인식하는 웹 앱. 뿌리의
[`../CLAUDE.md`](../CLAUDE.md) 가 두 버전 공통 규약(한글 식별자, 맞춰야 하는 값,
정확도 기준, 인코딩)을 담고 있으니 먼저 본다. 여기는 웹 버전에만 해당하는 것만 적는다.

## 외부 의존성이 없다

CDN, npm, 번들러, `package.json` 이 전혀 없다. `index.html` 이 받아 오는 것은
`web_version/` 폴더 안의 파일뿐이다. 브라우저의 표준 API(`fetch`, Canvas, ES 모듈)만 쓴다.

예외는 `도구/` 의 두 파이썬 스크립트뿐이며, 이들은 **빌드 시점에만** (즉 개발자가
가중치나 검증 데이터를 새로 만들 때만) 실행되고 브라우저에는 실행 시점에 존재하지 않는다.

**여기서는 학습하지 않는다.** 학습은 `desktop_version` 의 몫이다. 웹 버전은
`desktop_version/mnist_cnn.pt` 를 내보낸 결과물(`모델/`)을 읽어 추론만 한다.

## 로컬 실행 명령

브라우저의 `fetch` 는 `file://` 에서 막히므로 간단한 웹 서버로 열어야 한다.

```bash
python -m http.server 8765 --directory web_version
```

그다음 `http://localhost:8765/` 를 연다. 포트 8765 가 이미 쓰이고 있으면 다른
포트 번호로 바꾸면 된다.

## 검증 방법

`web_version/검증/검증.html` 을 같은 방식(로컬 서버)으로 열면 MNIST 평가 앞 200장을
브라우저 안에서 직접 추론해 점수를 보여 준다.

- 합격 기준: **190/200 이상**
- 현재: **199/200** (데스크톱 버전과 똑같이 43번 이미지 하나만 틀리며, 2를 4로 잘못 봄)

숫자가 떨어졌으면 의심할 곳은 두 군데다.

1. **전처리 6단계** (`js/전처리.js` 의 `전처리()`) — 경계상자 → 20px 축소(Lanczos3) →
   28×28 중앙 배치 → 무게중심 이동 → 정규화 순서가 `desktop_version/app.py` 와
   정확히 같은지 확인한다.
2. **평탄화 순서** (`js/신경망.js`) — 특징맵을 (채널, 행, 열) 순서의 1차원 배열로
   담는데, 이는 PyTorch 의 `flatten(1)` 과 같은 순서여야 한다. 순서가 어긋나면
   오류 없이 그냥 엉뚱한 숫자가 나온다.

## 알아 둘 점

**`drawImage` 로 크기를 줄이지 않는 이유.** 브라우저 내장 이미지 축소는 필터가
구현체마다 다르고 PIL 의 Lanczos 와 계수가 정확히 일치하지 않는다. 그래서
`전처리.js` 가 Lanczos3 커널 계산과 분리축(가로→세로) 리샘플링을 직접 구현해
PIL 의 결과를 재현한다.

**`파이썬반올림()` 이 따로 있는 이유.** 자바스크립트 `Math.round` 는 0.5 를
항상 위로 올리지만, 파이썬의 `round()` 는 짝수 쪽으로 반올림한다(banker's rounding).
축소 비율이나 무게중심 이동량 계산에서 이 차이가 픽셀 하나를 가르므로,
파이썬과 같은 규칙으로 반올림하는 함수를 따로 둔다.

**캔버스는 하나만 쓴다.** 데스크톱 버전은 tkinter Canvas(화면용)와 PIL
Image(인식용)에 같은 획을 이중으로 그리는데, 이는 tkinter Canvas가 픽셀을
되읽을 수 없기 때문에 어쩔 수 없이 쓰는 우회다. 웹은 `getImageData()` 로
캔버스 픽셀을 직접 읽을 수 있으므로 캔버스 하나로 화면 표시와 인식을 모두
처리한다. **데스크톱의 이중 그리기 구조를 웹에 따라 옮기지 말 것.**

**캔버스 내부 해상도는 고정한다.** `그림판.js` 는 `<canvas>` 의 `width`/`height`
속성을 항상 280(`캔버스크기`)으로 설정한다. 화면에 보이는 크기는 CSS 가 정하지만
내부 해상도는 CSS 크기와 무관하게 280×280 으로 고정해야, 화면 크기가 달라져도
`getImageData()` 로 얻는 픽셀 배열의 의미(1픽셀 = 캔버스 내부 좌표 1칸)가 항상 같다.
