# 손글씨 숫자 인식기 — 데스크톱 버전 (MNIST + PyTorch)

마우스로 숫자를 직접 써서 0~9를 인식하는 Windows 프로그램입니다.
학습된 모델의 MNIST 평가 정확도는 **99.07%** 입니다.

> 설치 없이 써 보려면 [웹 버전](../web_version/)을 보세요.
> 저장소 전체 안내는 [뿌리의 README](../README.md) 에 있습니다.
>
> **이 폴더가 학습을 담당합니다.** 재학습한 뒤에는 웹 버전이 쓰는 가중치도
> 다시 내보내야 합니다: `python web_version/도구/가중치_내보내기.py` (저장소 뿌리에서)

아래 명령은 모두 이 폴더(`desktop_version/`) 안에서 실행합니다.

## 내려받아 처음 실행하기

```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
pip install pillow numpy
python app.py
```

학습된 가중치(`mnist_cnn.pt`)가 저장소에 들어 있어서 바로 실행됩니다.
직접 학습시키고 싶으면 `python train.py` 를 실행하세요. MNIST 데이터는 자동으로 내려받습니다.

바탕화면 바로가기를 만들려면 (Windows):

```powershell
powershell -ExecutionPolicy Bypass -File .\바로가기_만들기.ps1
```

## 더블클릭으로 실행하기

**바탕화면의 `손글씨 숫자 인식기`** 를 더블클릭하세요. 검은 콘솔 창 없이 앱 창만 바로 뜹니다.

같은 바로가기가 프로젝트 폴더 안에도 있고, `손글씨앱 실행.bat` 을 더블클릭해도 똑같이 실행됩니다.

### 작업 표시줄에 고정하기

바탕화면의 바로가기를 **작업 표시줄로 끌어다 놓으면** 고정됩니다.
(또는 바로가기 우클릭 → `추가 옵션 표시` → `작업 표시줄에 고정`)

고정이 제대로 동작하도록 바로가기와 앱 양쪽에 같은 **앱 식별자(AppUserModelID)** 를 심어 두었습니다.

- 바로가기: `바로가기_만들기.ps1` 이 COM 인터페이스로 심음
- 앱: `app.py` 의 `앱식별자_등록()` 이 실행 시 등록

이 값이 없으면 윈도우가 앱을 `pythonw.exe` 로 인식해서, 고정해도 파이썬 기본 아이콘이 뜨고
고정한 항목을 눌러도 앱이 실행되지 않습니다. 두 곳의 값은 **반드시 같아야** 합니다.

```
DSMP.MNIST.HandwritingRecognizer
```

### 아이콘

`아이콘.ico` 는 `아이콘_만들기.py` 가 그려 낸 파일입니다.
파란 둥근 사각형에 손글씨체 숫자 `3` 과 필기 밑줄이 들어 있고,
윈도우가 요구하는 7가지 크기(16~256픽셀)를 한 파일에 담았습니다.

아이콘을 바꾸고 싶으면 `아이콘_만들기.py` 의 `배경색`, `글자색`, 글자(`"3"`)를 고친 뒤:

```
python 아이콘_만들기.py
powershell -ExecutionPolicy Bypass -File .\바로가기_만들기.ps1
```

### app.py 를 직접 더블클릭하고 싶다면

현재 이 PC에는 `.py` 확장자에 파이썬이 연결되어 있지 않아서, `app.py` 를 더블클릭하면
"이 파일을 어떻게 열까요?" 창이 뜹니다. 파일 연결은 시스템 설정이라 임의로 바꾸지 않았습니다.

직접 연결하고 싶다면 관리자 권한 명령 프롬프트에서 아래 두 줄을 실행하세요.
(이후로는 모든 `.py` 파일이 파이썬으로 열립니다)

```
assoc .py=Python.File
ftype Python.File="C:\Users\USER\AppData\Local\Programs\Python\Python314\python.exe" "%1" %*
```

다만 이렇게 하면 실행할 때마다 검은 콘솔 창이 함께 뜹니다.
콘솔 없이 깔끔하게 쓰려면 위의 바로가기를 쓰는 편이 낫습니다.

### 바로가기를 다시 만들어야 할 때

폴더를 옮겼거나 파이썬을 다시 설치해서 바로가기가 동작하지 않으면:

```powershell
powershell -ExecutionPolicy Bypass -File .\바로가기_만들기.ps1
```

바탕화면에는 만들지 않고 프로젝트 폴더에만 만들려면 뒤에 `-바탕화면제외` 를 붙이세요.

이 스크립트는 `C:\...\Microsoft\WindowsApps\` 안의 **마이크로소프트 스토어 별칭 스텁**을
걸러냅니다. 크기가 0바이트인 특수 파일이라 바로가기 대상으로 쓰면 제대로 동작하지 않기 때문입니다.
대신 `py -0p` 가 알려 주는 실제 설치 경로를 우선 사용합니다.

## 사용법

1. 왼쪽 검은 그림판에 마우스로 숫자를 씁니다.
2. 붓을 떼는 순간 자동으로 인식됩니다. (`인식하기` 버튼을 눌러도 됩니다)
3. 오른쪽에 예측 숫자와 0~9 각각의 확률이 막대그래프로 표시됩니다.
4. `지우기` 버튼으로 초기화합니다.

## 다시 학습시키기

```
python train.py
python train.py --에폭 10
```

에폭마다 평가해서 **정확도가 가장 높았을 때의 가중치만** `mnist_cnn.pt` 에 저장합니다.

## 인식률을 위한 전처리

화면의 그림을 그냥 28×28로 줄이면 인식률이 크게 떨어집니다.
그래서 `app.py` 의 `전처리()` 함수는 MNIST가 만들어진 방식을 그대로 따릅니다.

1. 글씨가 있는 영역만 잘라냄
2. 비율을 유지한 채 긴 변을 20픽셀로 축소
3. 28×28 도화지 가운데에 붙임
4. 픽셀 무게중심을 정확히 중앙(13.5, 13.5)으로 평행 이동

웹 버전의 `js/전처리.js` 가 이 함수를 그대로 옮긴 것입니다.
한쪽을 고치면 반대쪽도 함께 고쳐야 두 버전의 인식 결과가 어긋나지 않습니다.

## 참고: 배치 파일만 영문 주석인 이유

`손글씨앱 실행.bat` 은 이 프로젝트에서 유일하게 주석이 영문입니다.

`cmd.exe` 는 배치 파일을 **문자가 아니라 바이트 단위로** 읽으면서 위치를 추적합니다.
그래서 한글처럼 여러 바이트를 쓰는 글자가 들어가면 문제가 생깁니다.

- **CP949로 저장**: 한글의 두 번째 바이트가 ASCII 영역(`0x41~0x7A`)과 겹쳐서,
  cmd가 명령어 도중에 줄을 잘못 쪼갭니다.
- **UTF-8로 저장**: 이어지는 바이트가 모두 `0x80` 이상이라 위 문제는 없지만,
  cmd가 파일을 읽는 바이트 위치가 어긋나 `%PYTHONW%` 가 `YTHONW` 로 잘리는 식으로 깨집니다.
- **`chcp 65001` 추가**: 코드페이지를 바꾸는 순간 위치 추적이 더 심하게 어긋납니다.

실제로 세 가지 모두 시도해 봤고 전부 실행에 실패했습니다.
그래서 이 파일 하나만 ASCII로 두고, 한글 설명은 이 README에 옮겼습니다.
파이썬 코드(`model.py`, `train.py`, `app.py`)와 `바로가기_만들기.ps1` 은
모두 한글 주석 그대로입니다.
