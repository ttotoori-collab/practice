# 일본어 단어장 ♡ JLPT N5~N3

JLPT N5~N3 단어를 **모르는 것만 반복해서** 외우는 웹 앱입니다.
설치할 것이 없고 브라우저만 있으면 됩니다. 2000년대 Y2K 핑크 감성으로 꾸몄습니다.

**바로 써 보기 → <https://ttotoori-collab.github.io/practice/jlpt/>**

## 어떻게 쓰나요

1. 급수(N5 / N4 / N3)를 고릅니다.
2. 카드 가운데에 단어가 크게 나옵니다. 먼저 혼자 읽어 봅니다.
3. 아래 버튼으로 보고 싶은 것만 켭니다.
   - **히라가나** — 단어 위에 읽는 법 (青白い → あおじろい)
   - **훈음** — 한자마다 그 아래에 한국어 훈음 (青 → 푸를 청, 白 → 흰 백)
   - **뜻** — 단어 아래에 한국어 뜻 (창백하다)

   카드를 넘기면 세 버튼이 모두 꺼집니다. 새 단어는 언제나 한자만 보이는 상태로 시작해요.
4. 외웠으면 **알고있음**, 더 봐야겠으면 **공부하겠음** 을 누릅니다.
   - **알고있음** 을 누른 단어는 다시 나오지 않습니다.
   - **공부하겠음** 을 누른 단어만 모아서 다음 회차가 돌아갑니다.
5. 그 급수를 다 외우면 완료 화면이 나옵니다.

기록은 쓰는 브라우저 안(localStorage)에만 저장되어 새로고침해도 남습니다.
서버로 아무것도 보내지 않습니다. 지우고 싶으면 툴바의 🧹 **초기화** 를 누릅니다.

### 툴바

| 아이콘 | 하는 일 |
|---|---|
| 🏠 급수 | 급수 선택 화면으로 돌아갑니다 |
| 🔀 섞기 | 이번 회차에 남은 카드 순서를 다시 섞습니다 |
| 🧹 초기화 | 기록을 지웁니다 (이 급수만 / 전체 다 고를 수 있습니다) |
| ❔ 도움말 | 사용법을 말풍선으로 보여 줍니다 |
| 🌙 밤 모드 | 어두운 밤하늘 색으로 바꿉니다. 다시 누르면 ☀️ 낮 모드로 돌아갑니다 |

고른 모드는 저장돼서 새로고침해도, 기록을 초기화해도 그대로예요.

제목 표시줄의 **─** 는 창을 접고, **✕** 는… 눌러 보세요. 🎀

## 직접 띄워 보기

```bash
python -m http.server 8765 --directory jlpt_version    # 저장소 뿌리에서
```

<http://localhost:8765/> 에 접속합니다.
`index.html` 을 두 번 눌러 직접 여는 방식(`file://`)으로는 동작하지 않습니다.
브라우저가 `words.json` 읽기를 막기 때문입니다.

## 단어 추가하기

`데이터/words.json` 에 한 줄 더 적으면 끝입니다. 코드는 건드리지 않아도 됩니다.

```json
{ "level": "N3", "word": "青空", "reading": "あおぞら", "meaning": "푸른 하늘",
  "kanji": [{ "char": "青", "hunum": "푸를 청" }, { "char": "空", "hunum": "빌 공" }] }
```

| 칸 | 뜻 |
|---|---|
| `level` | 급수. `"N5"` `"N4"` `"N3"` |
| `word` | 화면 가운데에 크게 나오는 단어 |
| `reading` | 히라가나 읽는 법 |
| `meaning` | 한국어 뜻 |
| `kanji` | 단어에 나오는 **한자만** 순서대로. 가나는 적지 않습니다 |

- 한자가 없는 단어는 `"kanji": []` 로 둡니다. 훈음 버튼이 저절로 꺼집니다.
- `level` 에 `"N2"` 처럼 새 급수를 적으면 급수 버튼이 하나 더 생깁니다.
- 쉼표를 빠뜨리는 실수가 가장 많습니다. 형식이 틀린 항목은 앱이 건너뛰고
  브라우저 콘솔(F12)에 몇 번째 항목인지 알려 줍니다.

지금은 급수마다 30개씩, 모두 90개가 들어 있습니다.

## 만든 방식

- HTML · CSS · 자바스크립트만 씁니다. 빌드 도구도, 프레임워크도 없습니다.
- 바깥에서 받아 오는 것은 Google Fonts 글꼴뿐이고, 못 받아도 글꼴만 바뀝니다.
- 화면은 휴대폰 폭을 기준으로 만들었고, 누르는 버튼은 48px 이상입니다.
- 밤 모드는 색 변수만 갈아끼우는 방식이라 디자인(물방울·지브라·젤리)이 그대로 유지됩니다.
- 첫 화면 강아지는 `그림/리본강아지.png` 입니다. 바꾸고 싶으면 같은 이름으로 덮어쓰면
  됩니다 (배경이 투명한 PNG). 흰 테두리까지 그림에 들어 있습니다.
- 꾸밈(리본·별·하트·나비·반짝이·지브라 무늬·젤리 버튼)은 전부 CSS·SVG·이모지입니다.
