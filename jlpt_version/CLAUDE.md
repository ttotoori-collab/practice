# CLAUDE.md — 일본어 단어장

JLPT N5~N3 단어를 외우는 웹 앱. **빌드 도구도 번들러도 패키지 매니저도 쓰지 않는다.**
정적 파일을 그대로 서빙하면 끝이다. 저장소의 손글씨 숫자 인식기와는 코드를 공유하지
않는다. 같은 저장소에 얹혀 같은 GitHub Pages 사이트의 `/jlpt/` 아래로 배포될 뿐이다.

저장소 전체 규약은 뿌리의 [CLAUDE.md](../CLAUDE.md) 를 함께 본다.

## 명령어

```bash
# 로컬에서 띄우기 (file:// 로 열면 fetch 가 막혀 words.json 을 못 읽는다)
python -m http.server 8765 --directory jlpt_version    # 저장소 뿌리에서
# http://localhost:8765/ 접속
```

파이썬이 필요한 곳은 이 작은 서버뿐이다. 앱 자체는 브라우저만 있으면 된다.

## 변경 후 확인하는 법

자동 테스트가 없다. 화면을 건드렸으면 **휴대폰 폭(390px 정도)으로 창을 좁혀 놓고**
아래를 손으로 확인한다. 브라우저 개발자 도구의 콘솔에 빨간 줄이 없어야 한다.

1. 급수 화면에 N5·N4·N3 버튼 세 개가 나오고, 각 버튼에 "30개 중 n개 외움" 이 맞게 뜬다
2. 카드에서 히라가나·훈음·뜻 버튼을 켜면 각각 읽는 법·훈음·뜻이 나타난다
3. 한자가 두 자인 단어(예: 勉強)에서 훈음이 **한자마다 하나씩** 그 글자 아래에 붙고,
   긴 훈음(自由 의 "말미암을 유")도 **한 줄로** 나온다
4. 가나로만 된 단어(예: たくさん)에서 훈음·히라가나 버튼이 회색으로 꺼진다
5. "알고있음" 을 누른 단어가 다음 회차에 다시 나오지 않는다
6. "공부하겠음" 만 누르며 한 바퀴를 돌면 회차 표시가 2회차로 바뀌고 같은 단어들이 다시 나온다
7. 새로고침해도 외운 개수와 버튼 켜짐 상태가 그대로다
8. 🧹 초기화 → "전체 다" 를 누르면 모든 급수가 0개로 돌아간다
9. 가로 스크롤이 생기지 않고, 누르는 버튼의 높이가 48px 아래로 내려가지 않는다
10. **카드 속지가 흰 줄노트로 보인다.** 지브라 무늬는 카드 바깥 테두리에만 얇게 둘려 있고,
    카드를 넘기는 0.3초 동안에도 글씨 뒤로 비치지 않는다

`words.json` 만 고쳤다면 1·3·4 와 **콘솔 경고**만 봐도 된다.
형식이 틀린 항목은 앱이 건너뛰면서 콘솔에 몇 번째 항목인지 적어 준다.

## 구조

```
index.html          화면 뼈대 (창틀·툴바·세 화면·상태 표시줄)
스타일.css          Y2K 핑크 감성 전부. 색과 글꼴은 맨 위 :root 에 모여 있다
js/앱.js            조립. 화면 전환, 회차 관리, 공부시간 시계
js/단어저장소.js    words.json 을 읽어 화면이 쓰기 좋은 모양으로 손질
js/학습기록.js      localStorage 읽고 쓰기
js/카드.js          카드 한 장 그리기 (화면만 만지고 기록은 안 건드림)
js/꾸미기.js        쪽지 말풍선, 창 접기·닫기 장난, 시간 표시
데이터/words.json   단어 데이터. 이것만 고치면 단어가 늘어난다
```

ES 모듈(`<script type="module">`)을 쓴다. 그래서 파일을 나눠도 번들러가 필요 없다.

## 단어 추가하기

`데이터/words.json` 의 배열에 한 줄 더 적으면 끝이다. 코드는 건드릴 필요가 없다.

```json
{ "level": "N3", "word": "青空", "reading": "あおぞら", "meaning": "푸른 하늘",
  "kanji": [{ "char": "青", "hunum": "푸를 청" }, { "char": "空", "hunum": "빌 공" }] }
```

- `kanji` 는 **단어에 나오는 한자만** 순서대로 적는다. 가나는 적지 않는다.
- 한자가 없는 단어는 `"kanji": []` 로 둔다. 그러면 훈음 버튼이 저절로 꺼진다.
- `reading` 이 `word` 와 같으면(가나 단어) 히라가나 버튼도 저절로 꺼진다.
- `level` 에 `"N2"` 처럼 새 급수를 넣으면 급수 버튼이 하나 더 생긴다.
  버튼에 붙는 소개 문구는 `js/앱.js` 의 `급수소개` 에 적어 준다.

## 알아 둘 점

**훈음은 글자마다 붙는다.** `js/단어저장소.js` 가 단어를 한 글자씩 끊고 `kanji` 에서
찾은 훈음을 그 글자에 매단다. 그래서 `kanji` 의 순서가 단어 속 한자 순서와 달라도
자리를 맞게 찾아간다. 같은 한자가 한 단어에 두 번 나오면 먼저 적은 훈음을 둘 다 쓴다.

**속지는 반드시 불투명한 흰색이어야 한다.** 한때 글씨 뒤로 바깥 지브라 무늬가 비쳐
읽기 힘들었다. 원인이 둘이었고 `스타일.css` 에 둘 다 막아 두었으니 되돌리지 않는다.

- `.다이어리` 의 `background-color` 를 `background-image` 와 **따로** 적는다.
  한 줄짜리 `background` 로 묶으면 줄무늬 그림 한 겹이라도 브라우저가 못 읽을 때
  선언 전체가 버려져 종이가 투명해진다. 같은 이유로 `transparent 0 31px` 같은
  색 띄엄띄엄 적기도 쓰지 않는다. 옛 브라우저가 못 읽는다.
- 카드 등장 효과(`@keyframes 카드넘김`)에 `opacity` 를 넣지 않는다. 카드가 바뀔 때마다
  0.3초 동안 종이가 반투명해지면서 바깥 무늬가 비친다. 움직임은 `transform` 으로만 준다.

**훈음 칸은 너비를 고정하지 않는다.** `white-space: nowrap` 으로 한 줄을 지키고 너비는
글자 수에 맡긴다. 너비를 `em` 으로 묶어 두면 "말미암을 유" 같은 긴 훈음이 두 줄로 쪼개진다.
칸이 한자보다 넓어지면 글자 사이가 벌어지지만, 훈음을 끄면 다시 붙으므로 괜찮다.

**회차가 도는 방식이 이 앱의 핵심이다.** `js/앱.js` 의 `다음단어()` 한 군데에 모여 있다.
"공부하겠음" 은 `다음회차` 로 옮기고, "알고있음" 은 기록에 남기고 버린다.
`이번회차` 가 비면 `다음회차` 를 섞어 이번 회차로 삼는다. 둘 다 비면 완료 화면이다.

**localStorage 를 못 쓰는 브라우저가 있다.** 사생활 보호 모드에서는 읽기·쓰기가 예외를
던진다. `js/학습기록.js` 가 전부 try 로 감싸고 있으므로 **그 밖에서 localStorage 를
직접 부르지 않는다.** 기록이 안 되더라도 앱은 계속 돌아가야 한다.

**저장 열쇠는 `일본어단어장.기록.v1` 하나뿐이다.** 저장 형식을 바꿔야 하면 뒤의 번호를
올린다. 그래야 예전 형식을 읽다가 깨지지 않는다.

**공부시간은 1초마다 저장하지 않는다.** 10초마다, 그리고 탭을 숨기거나 닫을 때
(`visibilitychange`·`pagehide`) 저장한다. 다른 탭을 보는 동안에는 시간을 세지 않는다.

**글꼴은 Google Fonts 에서 받아 온다.** 이 앱에서 유일한 바깥 의존이다. 못 받아도
글꼴만 바뀌고 동작은 멀쩡해야 하므로 `:root` 의 글꼴 변수마다 대체 글꼴을 적어 두었다.

**경로는 전부 상대 경로다.** 배포되면 `/jlpt/` 아래에 놓이므로 `/` 로 시작하는 절대
경로를 쓰면 안 된다.

## 코드 규약

저장소 규약대로 **식별자와 주석이 모두 한글이다.** 자바스크립트 함수·변수, CSS 클래스
이름, HTML 의 `id` 까지 포함한다.

예외는 두 군데다.

| 자리 | 이유 |
|---|---|
| `데이터/words.json` 의 파일 이름과 `level`·`word`·`reading`·`meaning`·`kanji`·`char`·`hunum` | 사용자가 정해 준 데이터 형식. 바꾸면 사용자가 갖고 있는 파일과 어긋난다 |
| `js/` 안의 DOM API 이름 (`getElementById`, `addEventListener` 등) | 표준이 정한 이름 |

`js/단어저장소.js` 가 이 영문 필드를 읽어 한글 이름(`단어`·`읽는법`·`뜻`·`글자들`)으로
한 번에 바꿔 준다. **그 바깥에서는 영문 필드 이름이 나오지 않게 한다.**
